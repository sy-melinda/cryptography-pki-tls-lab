# Cryptography, PKI and TLS Security Lab

## Overview

This project documents a practical cryptography lab completed in a controlled Linux environment. The exercises demonstrate symmetric and asymmetric encryption, cryptographic key generation, certificate-authority configuration, certificate-signing requests and TLS certificate verification.

The lab used OpenSSL to encrypt files, generate RSA key pairs, create a local Certificate Authority and configure a certificate-protected web service.

> **Privacy notice:** Private-key material, personal identifiers and sensitive plaintext have been redacted from the screenshots.

## Objectives

- Encrypt and decrypt text and image files using AES.
- Generate a 2048-bit RSA public and private key pair.
- Protect data using public-key encryption.
- Create a local Certificate Authority.
- Generate and sign a Certificate Signing Request.
- Launch a TLS-enabled web server.
- Verify the generated certificate through a web browser.

## Technologies and Concepts

- Ubuntu Linux
- OpenSSL
- AES-128-CBC symmetric encryption
- RSA asymmetric encryption
- Public Key Infrastructure (PKI)
- X.509 certificates
- Certificate Signing Requests (CSR)
- Transport Layer Security (TLS)
